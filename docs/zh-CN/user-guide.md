## 快速开始

以域名解析托管在 Cloudflare 为例，从零开始得到一张自动续期的证书：

1. 登录后，在侧边栏选择组织和项目。
2. **集成配置 → 添加集成 → 签发方**：首次测试请选择“Let's Encrypt (staging)”，填写联系邮箱并勾选同意条款。
3. **添加集成 → DNS**：选择 *cloudflare*，粘贴具有该域名 *Zone:Read* 和 *DNS:Edit* 权限的 API 令牌。
4. **证书 → 申请证书**：名称例如 `www`，域名每行一个，签发方和 DNS 服务商选择刚才添加的。私钥保存位置保持“在 Certower 服务器上”，点击 **提交申请**。
5. 一两分钟内状态会变为“有效”。可以下载证书链，或通过 [Agent](#通过-agent-部署) 自动部署。
6. 测试成功后，添加正式的“Let's Encrypt”签发方并切换过去。此后 Certower 会自动续期。

## 基本概念

| 术语 | 说明 |
|---|---|
| **组织** | 一家公司或一个部门。下设项目、共用的集成配置、证书发现和成员。 |
| **项目** | 一起管理的一组证书，例如“网站服务”或“ERP”。权限和策略按项目生效。 |
| **证书** | 您希望存在的证书：域名、签发方、密钥类型、私钥存放位置。Certower 负责签发并持续续期。每次签发产生一个**版本**。 |
| **签发方** | 支持 ACME 协议的证书颁发机构（CA）账号：Let's Encrypt、ZeroSSL、Google Trust Services、Sectigo、GlobalSign、DigiCert、TWCA 等。 |
| **DNS 服务商** | Certower 用于创建临时 DNS 记录、证明您拥有该域名（DNS-01 验证）的凭据。 |
| **集成配置** | 签发方、DNS 服务商或通知渠道的配置。组织级配置由所有项目共用；项目级配置仅供该项目使用。 |
| **Agent** | 部署在您服务器上的小程序，私钥保存在本机，并负责把证书安装到 nginx 等服务中。 |
| **部署目标** | Agent 所在主机上安装证书的位置，例如“web-01 上的 nginx”。 |
| **策略** | 限制项目可以申请的内容：域名、CA、密钥类型、通配符、有效期。 |

## 登录

使用邮箱和密码登录，或在管理员已配置的情况下点击“使用 … 登录”进行单点登录。界面语言默认跟随浏览器设置，也可以在登录页或侧边栏底部切换（English、繁體中文、简体中文）。

- **修改密码**：侧边栏 → **修改密码**。您在其他设备上的登录会被退出。
- **忘记密码**：请系统管理员为您重置。
- 连续多次输错密码后，会暂时无法登录几分钟。
- 每次登录有效期为 12 小时。

## 角色

您能执行哪些操作，取决于您在组织或项目中的角色。在组织级别授予的角色，对组织下所有项目生效。

| 角色 | 权限 |
|---|---|
| **只读成员**（`viewer`） | 查看证书和证书发现结果。 |
| **操作员**（`operator`） | 只读成员的权限，外加使用已有的集成配置申请、续期、吊销和部署证书。 |
| **项目管理员**（`project_admin`） | 操作员的权限，外加管理集成配置及其密钥、Agent 和部署目标、证书发现端点、成员和 API 令牌，以及查看审计日志。 |
| **组织管理员**（`org_admin`） | 所有项目的项目管理员权限，外加创建项目和设置策略。 |
| **审计员**（`auditor`） | 只读成员的权限，外加查看审计日志。 |

所有内置角色都不能导出私钥，该权限只能通过自定义角色显式授予。**系统管理员**还可以管理用户账号和创建组织。

## 接入 CA 和 DNS 服务商

打开 **集成配置**（组织共用）或项目的 **项目集成配置**（仅供该项目使用；名称相同时项目配置优先），点击 **添加集成**。

### 签发方（CA）

| 字段 | 说明 |
|---|---|
| CA preset | 选择您的 CA，ACME 地址会自动填入。其他 ACME CA 请选择“自定义”。 |
| Contact email | CA 会把账号相关通知发送到这里。 |
| External Account Binding | ZeroSSL、Google Trust Services、Sectigo、GlobalSign、DigiCert、TWCA 需要。请从 CA 账号后台复制 *Key ID* 和 *HMAC key*。 |
| I agree to the CA's terms | 必须勾选。 |
| Default ACME profile | 可选，例如 Let's Encrypt 的 `shortlived`。 |

账号密钥会自动生成。敏感字段加密存储，保存后无法再次查看；如需更换，直接输入新值即可。

### DNS 服务商

Certower 使用 DNS-01 证明域名所有权：添加一条 TXT 记录，等到能查询到之后完成验证，再删除该记录。这种方式可以签发通配符证书，也适用于公网无法访问的内网服务器。

Cloudflare 请创建 API 令牌（*My Profile → API Tokens → Create Token → Edit zone DNS*），只授权需要的区域，权限为 *Zone:Read* 和 *DNS:Edit*。目前内置的 DNS 服务商是 Cloudflare，阿里云、腾讯云 DNSPod 等国内服务商的支持在规划中。

## 申请证书

**证书 → 申请证书**：

| 字段 | 说明 |
|---|---|
| 名称 | 简短的标识，例如 `www`。 |
| 域名 | 每行一个，第一个作为证书主体。`*.example.com` 需要策略允许通配符。 |
| 签发方、DNS 服务商 | 从集成配置中选择。 |
| 密钥类型 | ECDSA P-256 是现代的默认选择；需要兼容旧客户端时选择 RSA 2048 及以上。 |
| 私钥保存在哪里？ | **在 Certower 服务器上**：加密存储，立即签发，可下载为文件。**在 Agent 所在主机上**：在该主机生成，永不离开，绑定部署目标后才签发。 |
| ACME 配置文件（Profile） | 可选，否则使用 CA 默认值。 |
| 负责人邮箱 | 谁负责这张证书，会显示在证书页面上。 |

您会看到的状态：

| 状态 | 说明 |
|---|---|
| **等待签发** | 尚未签发（私钥放在 Agent 上的证书则是在等待绑定部署目标）。 |
| **有效** | 已有有效证书。 |
| **失败重试中** | 上次尝试失败，会按递增的间隔自动重试（从 1 分钟起，最长 6 小时）。页面上会显示错误原因。 |
| **需要处理** | 签发已暂停，需要有人排除原因，例如违反策略、申请被 CA 拒绝或配置不完整。 |

## 管理证书

打开一张证书，可以看到域名、私钥、当前版本、续期时间、历史版本和部署状态。

- **自动续期**：在 CA 建议的续期窗口内（ARI），或剩余三分之一有效期时。“续期时间”会显示预计的时间点。
- **立即续期**：立即加入续期队列，例如修改域名之后。
- **下载证书链**：PEM 格式的证书和中间证书。
- **吊销**：请求 CA 吊销当前版本，需要选择原因（私钥可能泄露时选择“私钥泄露”）。随后 Certower 会自动签发新证书替换。
- **删除**：Certower 停止管理此证书，并删除已保存的私钥。这**不会**吊销证书，如有需要请先吊销。

## 通过 Agent 部署

使用 Agent 时，私钥在您的服务器上生成，每次续期后也会自动安装证书并重载服务。

1. **Agent 与部署目标 → 添加 Agent**：填写名称（例如主机名），复制注册命令。令牌仅可使用一次。
2. 由管理员（或拥有该主机 root 权限的您）安装 Agent 并运行注册命令，参见[管理员手册](admin-guide.md#安装-agent)。完成后 Agent 会显示“在线”。
3. 在该 Agent 上 **新建部署目标**：
   - **nginx**：填写完整证书链和私钥的路径。Certower 会写入文件、执行 `nginx -t`、重载 nginx，并检查 `127.0.0.1:443` 是否已使用新证书；失败时会恢复旧文件。
   - **files（适用任何服务）**：写入证书文件，并可选执行主机允许的重载命令。
4. 在证书页面点击 **绑定部署目标**。“部署状态”区域会显示每个目标的状态和错误信息。

主机上的 `agent.json` 决定 Agent 可以写入哪些目录、执行哪些命令，因此指向其他位置的部署目标会失败，并给出明确的原因。详细说明参见 [Agent 说明](../agent.md)。

## 证书发现：找出未纳管的证书

**证书发现** 会检查您的服务器实际使用的证书，包括手动购买的证书、被遗忘的设备，以及其他团队的证书。

1. **添加端点**：每行一个，格式为 `host` 或 `host:port`（默认端口 443）。选择一个项目（项目成员可以查看，告警也会发送到该项目的通知渠道），或整个组织。
2. Certower 会立即扫描，之后每 12 小时扫描一次。**立即扫描** 可以重新扫描。
3. 按“有问题”或“未纳管”筛选，点击某一行可以查看详情。

| 发现的问题 | 说明 |
|---|---|
| 已过期／即将过期／尚未生效 | 有效期问题。 |
| 根证书已不受信任 | 证书链指向浏览器已不再信任其新签发证书的根证书，例如 2025 年 7 月 31 日之后的台湾中华电信。 |
| 域名不匹配 | 证书不包含该主机名。 |
| 证书链不受信任 | 缺少中间证书、自签名证书或私有 CA。 |
| SHA-1 签名、密钥强度不足 | 过时的密码算法。 |
| 有效期过长 | 超过签发时 CA/浏览器论坛规定的上限（2026 年 3 月 15 日起 200 天、2027 年 3 月 15 日起 100 天、2029 年 3 月 15 日起 47 天）。 |

“已纳管”表示服务器使用的正是 Certower 签发的那张证书。

## 通知

**集成配置 → 添加集成 → 通知**：

- **webhook**：格式可选 *json*（带签名，供您自己的系统使用）、*slack*（也适用于 Mattermost 和 Google Chat）或 *discord*。企业微信、钉钉、飞书的机器人可以通过 *json* 格式加一个中转服务接入。
- **email**：填写 SMTP 服务器、发件人和收件人。

每个通知渠道都可以限定事件类型和最低严重级别。点击 **发送测试** 确认配置正确。事件：

| 事件 | 时机 |
|---|---|
| 证书已签发 | 每次签发或续期后。 |
| 签发失败 | 某次尝试失败，或签发已暂停。 |
| 即将过期 | 到期前 21、14、7、3、1 天，以及到期时。 |
| 部署失败 | Agent 无法安装或验证证书。 |
| 发现告警 | 扫描发现严重问题。 |

详细说明和 Webhook 签名格式参见[证书发现与通知](../discovery-and-notifications.md)。

## 策略

组织管理员可以为每个项目设置 **策略**：

- **允许的域名**：例如 `*.example.com` 表示允许 example.com 下的所有域名。留空表示不限制。
- **允许的签发方**：集成配置的名称。留空表示不限制。
- **允许的密钥类型**。
- **允许通配符证书**：默认关闭。
- **最长有效期（天）**。

不符合策略的申请会被拒绝并说明原因；已有但不再符合策略的证书，在修正前会停止续期。

## 成员

**成员**（组织）和 **项目成员** 页面可以授予角色，对象可以是：

- **用户（邮箱）**：对方必须已有账号。
- **身份提供方（IdP）用户组**：该 SSO 用户组中的每个人都会获得此角色，权限自动跟随企业目录变化。
- **服务账号**（仅限项目）：配合 API 令牌用于自动化。

您只能授予自己拥有其全部权限的角色。

## 审计日志与任务队列

- **审计日志**（组织）：每一次变更由谁、在何时、从哪个地址操作。需要项目管理员、组织管理员或审计员角色。
- **任务队列**（项目）：后台任务列表，包括签发、续期、通知和扫描，以及尝试次数和最近一次错误。

## 常见问题

**Certower 能续期我现在付费 CA 的证书吗？** 只要该 CA 提供 ACME（目前大多数都支持，通常需要外部账号绑定 EAB）就可以。不支持的话，也可以通过证书发现持续跟踪。

**Certower 停机一天会怎样？** 不会有明显影响：证书会在到期前数周续期，Certower 恢复后会继续处理。

**私钥存放在哪里？** 保存在服务器上的私钥，加密存储在 Certower 的数据库中；保存在 Agent 上的私钥，只存在于该主机。

**可以使用 API 吗？** 可以。界面上的所有操作都可以通过 [REST API](../api.md) 完成，自动化场景请使用服务账号的令牌。
